HOW TO BUILD PGC_SMP_Installer.exe
====================================

You need a Windows machine with PowerShell (built into Windows 10/11).
This cannot be done on Linux/Mac - ps2exe only compiles real Windows .exe
files on Windows itself.

STEPS
-----
1. Copy this whole folder to your Windows PC. It should contain:
     - Install-PGC-SMP-GUI.ps1
     - PGC_SMP_1_0_0.mrpack
     - build-exe.ps1
     - HOW-TO-BUILD-THE-EXE.txt (this file)

2. Right-click "build-exe.ps1" -> "Run with PowerShell".
   (If Windows blocks it, right-click the file -> Properties -> check
   "Unblock" at the bottom -> OK, then try again. Or open PowerShell in
   the folder and run:  powershell -ExecutionPolicy Bypass -File .\build-exe.ps1)

3. First run only: it will auto-install the "ps2exe" PowerShell module
   for your user account. This needs internet access. If it fails due to
   permissions, open PowerShell as Administrator and run:
     Install-Module ps2exe -Scope CurrentUser -Force
   then re-run build-exe.ps1.

4. When it finishes you'll have "PGC_SMP_Installer.exe" in the same folder.

DISTRIBUTING IT
----------------
Ship these two files together in the same folder:
   - PGC_SMP_Installer.exe
   - PGC_SMP_1_0_0.mrpack

The installer reads its own folder to find the .mrpack next to it, so
they must stay together (this is the fix already built into v1.2.0 -
it resolves its folder via the running process path when compiled).

You no longer need the .bat file or the raw .ps1 for end users once you
have the .exe - those were only needed to run it as a script.

NOTES
-----
- SmartScreen / antivirus: unsigned exes from ps2exe are commonly flagged
  by Windows SmartScreen or some antivirus since they're unsigned. This is
  a false positive, but if it's an issue for your users, you'd need a code
  signing certificate to sign the exe (a separate, paid process).
- The .exe is not admin-elevated (-requireAdmin:$false) since installing
  to %APPDATA%/.minecraft doesn't need admin rights.
